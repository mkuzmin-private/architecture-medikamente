### Работа с данными
1. В системе выделяются следующие категории данных:
   - Персональные данные (PII) - ФИО, адрес, места работы учёбы, телефон, почта и т.д
   - Специальные данные (PHI) - данные о здоровье, включая заболевания, диагнозы и анализы.
   - Коммерческая тайна - финансовые данные, данные об оборудовании, персонале
   - Публичные данные - маркетинговая информация, расписания докторов, данные о компании.
2. Персональные данные, специальные данные и данные составляющие коммерческую тайну должны шифроваться при хранении и передаче.
3. Каждому пользователю присваивается своя роль в системе. Доступ к роли определяется на основе RBAC/ABAC. Соблюдается принцип минимальных привилегий.
   - Администратор может просматривать только записи на прием. При этом может видеть только ФИО пациента, ФОИ врача и время записи на прием. Доступа к мед.картам/анализам нет.
   - Бухгалтер имеет доступ только к данным оплаты услуг и договорам. Доступа к записям на прием и мед картам клиентов нет.
   - Доктор может просматривать данные пользователя, которые касаются приема (мед. карты, анализы, ФИО, история хронических заболеваний из анкеты). При этом у доктора отсутствует доступ к паспортным данным, телефону. Доктор также имеет доступ только к данным своих пациентов.
   - Пациент может просматривать/редактировать все свои данные в профиле. При этом у пациента нет доступа к каким-либо данным других пациентов.
   - Аналитики не имеют доступа к персональным данным пользователей. Вместо этого они работают с маскированными данными.
4. Сервисы между собой взаимодействуют по защищенному протоколу TLS 1.2+.
5. Все действия пользователей логируются через специальный сервис
6. Передача данных внешним партнерам в лабораторию осуществляется в маскированном виде.
7. Результаты анализов хранятся в зашифрованном виде (AES-256)
8. Данные клиентов, включая их медицинские данные, должны удаляться, в случае письменно запрос от клиента. Сроки хранения данных в электронном виде регулируются нормативными документами Минздрава России (анализы как минимум 1 год, медкарты 50 лет).
9. Персональные данные клиентов храним только в одной базе, другие базы должны хранить только идентификаторы пользователей.
